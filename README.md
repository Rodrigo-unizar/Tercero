## 📝 Sobre este repositorio
Este espacio centraliza todo mi trabajo académico (teoría, prácticas, scripts y proyectos) durante el **tercer curso del Grado en Ingeniería Informática** en la **Universidad de Zaragoza (UNIZAR)**. 

El contenido está enfocado en la rama de **Tecnologías de la Información (TI)**, cubriendo los 60 créditos ECTS divididos en 10 asignaturas (5 por cuatrimestre), incluyendo mi optativa de Aprendizaje Automático.

---

## 📚 Plan de Estudios (Asignaturas)

### 🍂 Primer Cuatrimestre
| Acrónimo | Asignatura | Descripción |
| :---: | :--- | :--- |
| **PHW** | **Proyecto Hardware** | Diseño y programación a nivel hardware, sistemas empotrados y control de periféricos. |
| **SISINF** | **Sistemas de Información** | Arquitecturas empresariales, modelado de procesos, bases de datos avanzadas y gestión de sistemas. |
| **ING SW** | **Ingeniería de Software** | Metodologías de desarrollo (ágiles y tradicionales), patrones de diseño, testing y calidad del software. |
| **SD** | **Sistemas Distribuidos** | Arquitecturas cliente-servidor, paso de mensajes, concurrencia, tolerancia a fallos y sincronización de relojes. |
| **IA** | **Inteligencia Artificial** | Resolución de problemas mediante búsqueda, algoritmos heurísticos, juegos y representación del conocimiento. |

### 🌸 Segundo Cuatrimestre
| Acrónimo | Asignatura | Descripción |
| :---: | :--- | :--- |
| **ADSIS 2** | **Administración de Sistemas 2** | Gestión avanzada de servidores (Linux/Windows), scripting (Bash/PowerShell), virtualización y contenedores. |
| **BBDD 2** | **Bases de Datos 2** | Optimización de consultas, gestión de transacciones, arquitecturas NoSQL y administración del SGBD. |
| **A AUTO** | **Aprendizaje Automático** *(Optativa)* | Modelos de Machine Learning: clasificación, regresión, clustering y evaluación de modelos usando Python. |
| **SEG** | **Seguridad Informática** | Criptografía, gestión de identidades, análisis de vulnerabilidades, auditorías y fortificación de sistemas. |
| **TW** | **Tecnologías Web** | Desarrollo Full-Stack, creación de APIs REST, frameworks actuales y despliegue de aplicaciones web. |
